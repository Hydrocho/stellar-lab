# 별빛 연구소

빌드와 외부 라이브러리 없이 실행하는 HTML/CSS/JavaScript 학습 게임입니다.
루트 `index.html`을 브라우저로 열고, 함께 제공된 JS/CSS 파일을 같은 폴더에 두세요.

## 1단계: 탐침 관측과 도감
1. 우주 시점에서 드래그·터치·방향키로 하늘을 둘러봅니다. 상하/좌우 연속 회전이 가능합니다.
2. 별을 중앙 십자선에 1초간 유지하면 관측 장비가 열립니다. 별을 직접 눌러 선택하지 않습니다.
3. 그래프를 드래그하거나 파장 슬라이더, ±1 nm 버튼으로 탐침을 움직입니다.
4. 그래프의 높이를 비교하여 최대 세기 지점을 찾습니다. 탐침 파장 옆에는 표면 온도가 표시되며, 최대점을 찾기 전에는 측정 중으로 표시됩니다. 최대 세기의 99.5% 이상이면 등록할 수 있습니다.
5. ‘온도 자동 측정 · 카드 등록’을 누르면 온도·유형과 관측 카드가 공개됩니다.
모든 별에 같은 실험을 적용하며 유형 맞히기, 두 별 비교, 온도 입력은 없습니다.
O/B/A/F/G/K/M 각 3개, 총 21개의 서로 다른 별을 수집하면 2단계가 열립니다.

## 도감과 기록
‘수집 도감’에서 등록한 카드를 다시 볼 수 있습니다. 초기화는 확인 후 도감과 1단계 통과 상태만 지우며 게임 기록은 유지합니다.
localStorage `stellar-lab-v1`을 사용합니다. 기존 수집 기록과 호환됩니다.

## 2단계: 60초 별 사냥
0.4초 조준으로 포착합니다. 기본 +100점, 3연속 ×1.5, 5연속 ×2. 오답은 −30점(최소 0점)과 콤보 해제입니다.
마지막 10초는 획득 점수에 ×2가 추가 적용됩니다. 포착한 별은 5초간 흐리게 표시되고 재획득할 수 없습니다.
일반 목표는 O~M형을 섞어 7종을 한 번씩 순환하며, 순환 경계의 같은 유형 연속 출제를 피합니다. 20초·40초가 지나면 특별 미션을 대기시키고 현재 목표를 맞힌 뒤 시작합니다. 미션은 서로 다른 두 유형을 순서대로 찾으며 시작부터 10초입니다. 포착 횟수가 적은 유형 중 포착 가능한 유형을 우선하며, 동률은 무작위로 선택합니다. 온도 미션은 O~M 전체 구간(하한 포함, 상한 제외)에서 출제합니다. 미션 성공 후에는 직전에 찾은 유형과 다른 일반 목표를 제시합니다. 시간 초과 시 보너스만 종료하고 현재 목표 유형은 유지합니다. 성공 보너스 +200점에는 배수가 적용되지 않습니다. 시간 초과 시 일반 목표로 돌아옵니다.
완주 등급: S ≥3200 / A ≥2400 / B ≥1600 / C ≥800 / D <800. 중도 종료는 미완주로 저장합니다.
새 기록은 rulesVersion 2, 최고 콤보, 성공 미션 수를 저장합니다. 기존 기록은 기존 규칙으로 구분합니다.
최근 500회 게임 기록을 보관하며 ‘오늘의 기록’은 기기의 현지 날짜 기준입니다.

## 과학 모형
스펙트럼은 교육용 흑체 복사 모형이며 실제 별의 흡수선 자료가 아닙니다.
그래프는 별마다 최대 세기를 100으로 정규화합니다. 가시광선 띠는 그래프 바로 아래 380~780nm의 동일한 파장 위치에 놓이며, 그래프와 동일한 기준으로 세기를 밝기에 반영합니다. 색은 화면용 모식 표현입니다. 탐침이 가시광선 밖으로 이동하면 자외선 또는 적외선으로 표시합니다.
자동 온도 표시는 모형의 표면 온도이며 탐침은 최대점 부근의 측정 구간을 찾는 활동입니다.

## 검증
루트에서 `node --test *.test.cjs`를 실행합니다.

## 포착 연출
2단계에서 정답으로 선택한 별만 0.75초간 폭발한 뒤 현재 카메라의 뒤쪽 반구에 재배치됩니다. 오답 별은 이동하지 않으며 오답·감점 안내를 표시합니다. 폭발 중 재선택은 차단하며 별의 유형·온도·개수는 유지합니다. 정답 별의 기존 5초 재획득 대기시간도 유지합니다. 초신성 효과는 실제 별의 진화를 재현하는 것이 아닌 게임 연출입니다.
