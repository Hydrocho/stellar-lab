# 별빛 연구소

빌드와 외부 라이브러리가 필요 없는 한국어 천문 학습 게임입니다.

`dist/index.html`을 브라우저로 열면 실행됩니다. 안정적인 저장소 동작을 위해서는 정적 웹 호스팅 또는 `python -m http.server 8080 --directory dist` 사용을 권장합니다. 파일 열기와 웹 호스팅은 서로 다른 저장소를 사용합니다.

- 1단계: 21개의 교육용 모형별 관측 → 버튼으로 표면 온도 자동 측정 → O/B/A/F/G/K/M 각 3개 수집
- 2단계: 1단계 완료 시 해제, 60초 동안 목표 유형 탐색, 정답 +100 / 오답 −30
- 등급: A+ 1500, A 1200, A− 900, B 600, C 300, D 그 미만. 중도 종료는 D.
- localStorage `stellar-lab-v1`에 진행과 최근 500회 기록 저장. 오늘의 기록은 기기의 현지 날짜 기준.
- 흑체 모형 곡선이며 실제 천체의 관측 자료나 흡수선 스펙트럼은 아닙니다. 표의 대표 별은 유형을 설명하기 위한 참고 예시입니다.

추가 기능 제안: 온도 순서대로 별 배열하기, 흡수선 비교 실험, 색상 단서 없이 스펙트럼으로 찾는 심화 모드, 오답 유형 복습, 교사용 기록 CSV 내보내기.
